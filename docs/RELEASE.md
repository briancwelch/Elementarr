Elementarr 0.4.1 enables public automatic updates without a GitHub account or token. Windows installations check for signed stable releases after startup and every six hours, with automatic installation enabled by default.

The update settings no longer ask for GitHub credentials. Existing check/install preferences are preserved, and saved legacy update tokens are discarded. Publisher signatures, payload checksums, protected application data, and failed-startup rollback remain enforced.

The README now provides a short installation and setup guide, including Plex sign-in, TMDB metadata access, tray controls, and automatic updates.
